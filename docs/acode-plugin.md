# Plugin Acode

Download: tombol **Install** di section "Unduh Plugin" pada website → `lentera-acode.zip`.

## Install

1. Buka Acode → **Settings** → **Plugins**
2. Pilih **Install from .zip**
3. Pilih file `lentera-acode.zip`
4. Restart Acode kalau plugin belum langsung aktif

## Pakai

1. Buka file kode apa saja
2. Kalau ada error (garis merah di editor), tombol lentera oranye di pojok kanan bawah **berkedip**
3. Ketuk tombol untuk buka panel — isinya baris error dan kemungkinan penyebabnya

## Catatan

Acode Plugin API bisa berbeda antar versi Acode. Kalau plugin gagal load, cek dokumentasi resmi Acode Plugin Development untuk menyesuaikan nama API terbaru di `www/main.js`.
