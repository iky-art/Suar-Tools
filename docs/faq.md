# FAQ

**Apa bedanya Lentera dengan Eruda?**
Eruda menampilkan console mobile secara umum. Lentera fokus menjelaskan kemungkinan penyebab error dalam Bahasa Indonesia, bukan cuma menampilkan log mentah — dan dibangun dari nol tanpa memakai kode Eruda.

**Apakah Lentera gratis dipakai?**
Ya. Lentera bisa ditempel langsung ke halaman apa pun tanpa biaya, tanpa akun.

**Apakah plugin VS Code dan Acode sudah bisa dipakai?**
Sudah tersedia untuk diunduh di halaman "Unduh Plugin" pada website — masih di versi awal (v0.1.0), jadi kalau menemukan bug, wajar dan bisa terus dikembangkan.

**Bisa dipakai di proyek yang tidak pakai React?**
Bisa. Lentera hanya butuh satu tag script, jadi bisa dipakai di HTML biasa, Vue, Svelte, atau framework apa pun.
